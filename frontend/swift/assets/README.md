# DittoCard Quick Start

1. Drag `DittoCard.app` to Applications and open it.
2. Connect and unlock your iPhone, then trust this computer.
3. Click **Scan Cards**. Open the target card in Wallet on the phone.
4. Click **Read Artwork** to save the first backup.
5. Choose an image, adjust the preview, then click **Apply Artwork** to confirm.
6. Use **Restore First Backup** to restore the original artwork.

If an operation is interrupted, reconnect the same phone and use **Continue Recovery**. Keep the app's backup and transaction data until recovery is complete.

This locally built app is available for the architecture used during the build. Device operations require a supported iOS build; a successful installation alone does not confirm device compatibility.

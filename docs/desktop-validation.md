# DittoCard 验证记录

本文件区分已在设备上完成的操作、仅完成的本地构建，以及尚未验证的范围。构建步骤见[双端构建指南](desktop-build.md)。下列历史结果对应记录日期的设备和代码，不代表其他系统版本也已通过。

## Windows 11 x64（2026-09-23）

在 Microsoft Store 版 iTunes、iOS 27.0（`24A437`）与 USB 连接的 iPhone 上，已完成：

- 设备发现、卡片扫描与分类、卡面读取和首次备份校验。
- 对指定测试卡片生成预览，确认后更换卡面；用户在手机 Wallet 中确认显示结果。
- 恢复首次备份，校验原文件及原本缺失文件的状态；用户确认原卡面恢复。
- 中断后的事务续接、临时文件清理、含中文及空格路径的备份导出。
- NSIS 安装包在测试机器上安装和启动；冻结后端及桌面冒烟测试通过。

这些结果不覆盖其他 iTunes 安装方式、Windows ARM64、其他 iOS 构建或未安装开发工具的独立机器。

## macOS 跨端版（2026-09-24）

在 arm64 Mac 上完成原生 helper、冻结后端、Tauri 应用与 DMG 构建；应用启动、设备自动发现、语言与主题切换通过。一次真机扫描未取得预期的读取副本，相关事务已保留并将对应卡片隔离；该轮没有执行卡面写入。因此 macOS 的卡面读取、更换和恢复仍未通过真机验收。

当时的安装包为本地测试产物，未做发行签名或公证。macOS 14 至 26、Intel 构建及其他设备组合尚未验证。

## macOS SwiftUI 版（2026-09-24）

arm64 应用与 DMG 构建、启动、已缓存卡面的离线预览、选图、裁剪预览和设置菜单通过本机检查。界面使用与跨端版相同的事务后端；真机读取、更换和恢复尚未执行验收。

## 目录整理后的本地复核（2026-09-24）

- 后端自动化测试：77 项运行，1 项按环境跳过，其余通过。
- 跨端前端测试：8 项通过；TypeScript 与 Vite 生产构建通过。
- 跨端 Python 后端冻结打包通过，打包后的 `hello` 协议返回正常。
- SwiftUI arm64 应用和 DMG 完整构建通过。
- 本机缺少 Cargo，因此目录整理后的 Tauri 完整安装包尚未在这台机器上重新构建。
